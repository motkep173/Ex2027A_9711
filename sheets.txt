# דפי ההגשה שכבר נפתחו לסטודנטים, והתרגילים שבכל דף.
# תרגיל שמופיע כאן מסומן "דף הגשה N" בחוברת התרגילים (PDF) ובאתר, ובאתר אפשר לסנן לפי דף.
#
# שורה שמתחילה ב-"## " היא מספר הדף. אחריה, שורה לכל תרגיל:
#   seq-006 ב ג ה     הסעיפים (ב), (ג), (ה) של התרגיל seq-006
#   seq-008           התרגיל כולו
# כותבים את המזהה של התרגיל, ולא את המספר שלו בחוברת: המספר עלול להשתנות, והמזהה לא.
# שורות שמתחילות ב-# הן הערות.
#
